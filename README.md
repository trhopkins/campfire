# Campfire

A minimal, broadsheet-style Hugo theme: serif type, masthead, dateline, multi-column front page. One small hand-written stylesheet (`assets/css/main.css`), no build step, no JavaScript, automatic dark mode.

## Installation

```sh
git submodule add https://github.com/trhopkins/campfire themes/campfire
echo "theme = 'campfire'" >> hugo.toml
```
